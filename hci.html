Primary Project: LanKrong

Urban Transit UX Solution • Mobile App

LanKrong (ẜ۩ក្រុង) — Bus Navigation & Ticketing

LanKrong is a mobile UI designed to solve public transit friction for bus riders in Phnom Penh. By prioritizing clear route visibility, real-time bus tracking, and fast digital ticketing, the platform reduces daily user frustration and cognitive overload.

Weekly Progress & Deliverables

02
Phase 1 • Weeks 1–3

Needfinding & User Personas

Conducted user research and field observations with daily commuters. Created targeted user personas, journey maps, and empathy maps highlighting key pain points in public transit navigation.

Phase 2 • Weeks 4–6

Information Architecture & Low-Fi Wireframes

Structured app navigation logic and sitemap. Sketched low-fidelity paper wireframes to rapidly test layout concepts, ticket purchase flows, and bus route search UX.

Phase 3 • Weeks 7–9

Hi-Fi Interactive Figma Prototype

Translated paper sketches into high-fidelity Figma components. Established custom design tokens, accessible color contrasts, and interactive screen transitions.

Phase 4 • Weeks 10–12

Usability Testing & Heuristic Evaluation

Executed task-driven usability tests with peers. Evaluated results against Jakob Nielsen's 10 Usability Heuristics, making key UI iterations to improve system status visibility.

Personal Reflection

03

Reflection on My HCI Journey

Working on LanKrong fundamentally shifted my perspective as a Computer Science student. Previously my focus leaned heavily on backend logic, database structures, and server performance. This HCI course demonstrated that technical power means little if the end user faces friction or cognitive overload. Through iterative wireframing, user testing, and component prototyping in Figma, I gained a deep appreciation for user-centered design, usability heuristics, and accessible interface engineering.
