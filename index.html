BookLan App

A mobile app prototype designed to fix Cambodia's biggest intercity travel problem: passengers stranded on national roads have no way to book a passing bus or van, since private companies only accept riders with pre-booked tickets from a station. Built through user research, competition validation, and iterative design in Figma, BookLan turns rigid station-based booking into an on-demand experience: pin your location, see nearby buses, and book a seat from anywhere on the road. This is a UX research and product design project, the full prototype lives in Figma.

Parking Management System

Parkin' is a parking management system I built for my database class. Laravel and MySQL, handles the whole parking lifecycle: check vehicles in, assign them to slots by zone, calculate fees at checkout, track everything in history with admin reports. This project is where SQL actually clicked for me. Laravel gives you Eloquent so you write stuff like Ticket::where('status', 'active')->get(), but underneath it's always real SQL. Every check-in is an INSERT, every checkout updates multiple tables, every report is a JOIN or subquery. Once I started thinking about the actual SQL running behind Eloquent, everything made more sense.

School Management System

Cambodia High School is a school management system I built with a teammate for my web course. Laravel and MySQL, handles everything a real school needs: students, teachers, classes, attendance, exams, homework, and announcements. Before writing any code, I went to Sisowath High School and interviewed a teacher to understand how the Cambodian public school system actually works, grading, attendance, all of that. Then we designed the whole system flow and changed it so many times along the way. The biggest thing I learned is it's not really about the code. It's about the logic and the architecture. A student belongs to a class, a class has a teacher, admin manages the staff, everything ties into each other like a chain. The most complex part was the schedule system. Teachers submit their available time slots, admin reviews and approves them, and once it's all set, teachers teach based on that and students get their timetable by class. Last thing I added was Khmer language support, first time I did something like that. The concept is simple, you have a folder storing all the translations, and when the user switches the language, the app just points to that folder and swaps everything out..
